# EnergyShark · Frontend

SPA React de la ciudad REE. Primera etapa: RF01 con datos de ejemplo. La API y autenticación se conectarán cuando el equipo defina sus contratos.

## Ejecutar

```sh
npm install
npm run dev
```

Abrir la URL que muestre Vite, normalmente `http://localhost:5173`.

## Para conectar RF01

Acordar con P3 y P4 el OpenAPI de listado y detalle de ciclos: `cycleId`, estado recibido, fondos, órdenes, negociaciones, reporte, saldos finales y última operación aplicada. El `/history` de E0 aún no entrega esta vista.
